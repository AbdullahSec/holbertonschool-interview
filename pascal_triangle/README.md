# Pascal's Triangle

## Description
This project implements a Python function that generates Pascal's triangle for a given integer `n`.

## Requirements
- OS: Ubuntu 20.04 LTS
- Python version: Python 3.8.x
- Style: PEP 8 (`pycodestyle`)
- Allowed editors: `vi`, `vim`, `emacs`

## Tasks Overview
- `0-pascal_triangle.py`: Function `def pascal_triangle(n):` returning a list of lists of integers representing Pascal's triangle of `n`. Returns an empty list if `n <= 0`.
